# مرصد التقديرات السكانية

موقع محلي بلغة Python‏ (Flask) لتحليل البيانات السكانية والتنبؤ بها باستخدام طرق إحصائية كلاسيكية، مع مساعد تفاعلي يعرض النتائج على شكل رسومات وجداول وقراءات كلامية.

## الخصائص
- رفع ملف Excel‏ (.xlsx) أو CSV يحتوي على أعداد السكان حسب المحافظة / المنطقة / الحي / الفئة العمرية للأعوام المتاحة.
- اكتشاف بنية البيانات تلقائياً (صيغة عريضة بأعمدة سنوات، أو صيغة طولية بعمود سنة وعمود عدد).
- ملخّص سريع فوري: بطاقات إحصائية + رسم تطوّر الإجمالي + معاينة الجدول.
- مساعد منبثق يتيح اختيار السؤال:
  - السكان حسب المحافظة
  - التوزيع حسب الفئة العمرية
  - تطوّر السكان زمنياً (مع معدّل النمو المركّب)
  - مقارنة النمو بين سنتين
  - عمليات حسابية مخصّصة (مجموع/متوسط/وسيط/أعلى/أدنى/انحراف معياري)
  - **التنبؤ بعدد السكان للسنوات القادمة باستخدام نموذج ARIMA** مع فترات ثقة 95٪
- مرشّحات متتالية (محافظة ← منطقة ← حي ← فئة عمرية).
- **مساعد تحليلي صوتي** بجانب النصي: ينطق المستخدم سؤاله فيُفرَّغ محلياً عبر faster-whisper، ثم يُربط بإحدى الأسئلة المتاحة نفسها وتُملأ المرشّحات تلقائياً ليؤكّدها المستخدم قبل العرض. الفهم حتمي (مطابقة كلمات وكيانات) بلا أي نموذج توليدي.

> ملاحظة: لا يُستخدم أي ذكاء اصطناعي توليدي ولا أي خدمة خارجية. كل الحسابات تُجرى محلياً على جهازك وتُشتقّ من ملفك فقط.

## التشغيل على VSCode (Python 3.13)

```bash
# 1) داخل مجلّد المشروع، أنشئي بيئة افتراضية
python -m venv .venv

# 2) فعّلي البيئة
#    على ويندوز:
.venv\Scripts\activate
#    على ماك/لينكس:
source .venv/bin/activate

# 3) ثبّتي المتطلبات
pip install -r requirements.txt

# 4) شغّلي التطبيق
python app.py
```

ثم افتحي المتصفّح على العنوان:

```
http://127.0.0.1:5000
```

للتجربة السريعة، استخدمي الملف الجاهز في مجلّد `sample_data/`.

## المساعد الصوتي (Vosk)

يعمل التعرّف الصوتي محلياً عبر محرّك Vosk (يناسب أي معالج ويعمل دون إنترنت بعد تنزيل النموذج مرّة واحدة). خطوات الإعداد:

1. ثبّتي المحرّك:
   ```
   python -m pip install vosk
   ```
2. نزّلي نموذج اللغة العربية (نحو 318 ميجابايت):
   `https://alphacephei.com/vosk/models/vosk-model-ar-mgb2-0.4.zip`
3. فكّي ضغط الملف، ثم ضعي محتوى المجلد داخل مجلّد المشروع بهذا المسار:
   ```
   population_app/models/vosk-ar/
   ```
   بحيث يحتوي `models/vosk-ar/` مباشرةً على مجلّدات النموذج (am, conf, graph, ...).
   - بديلاً، يمكنكِ وضع النموذج في أي مكان وتمرير مساره عبر متغيّر البيئة:
     - ويندوز: `set VOSK_MODEL=C:\path\to\vosk-model-ar-mgb2-0.4` ثم `python app.py`
4. شغّلي التطبيق: `python app.py`

- التسجيل من المتصفّح يُحوَّل تلقائياً إلى صيغة WAV المناسبة داخل المتصفّح، فلا حاجة لأي أدوات صوت على النظام (ولا ffmpeg).
- إن لم يكن Vosk مثبّتاً أو لم يوجد مجلّد النموذج، يبقى المساعد النصي يعمل طبيعياً وتظهر رسالة إرشادية واضحة عند محاولة استخدام الصوت.
- يعمل التسجيل على `http://127.0.0.1:5000` لأن المتصفّحات تعدّ localhost سياقاً آمناً للميكروفون.

## صيغة البيانات المدعومة

**الصيغة الطولية** (مفضّلة):

| المحافظة | المنطقة | الحي | الفئة العمرية | السنة | عدد السكان |
|----------|---------|------|----------------|-------|------------|
| العاصمة | قصبة عمّان | حي 1 | 15-29 | 2020 | 12000 |

**الصيغة العريضة** (أعمدة لكل سنة):

| المحافظة | المنطقة | الفئة العمرية | 2018 | 2019 | 2020 |
|----------|---------|----------------|------|------|------|
| إربد | الرمثا | 0-14 | 9000 | 9300 | 9600 |

الأعمدة غير المتوفّرة (مثل الحي) تُعامَل تلقائياً كقيمة موحّدة، فلا حاجة لوجود جميع الأبعاد.
